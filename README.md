# PyGameCorrida

link video: https://youtu.be/GY0U5iriuRI

O jogo foi feito essencialmente com auxílio de Inteligencia Artificial (ChatGPT). O processo de criação se deu com os integrantes do grupo reunidos para escolher e o jogo que seria feito e ir dando os comando para a IA. Os integrantes fizeram varios ajustes no jogo com o auxílio da IA. O código do jogo foi dividido entre os três integrantes por meio o GitHub.
